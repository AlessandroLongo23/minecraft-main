*Voucher*

![[voucher_end_portal.png|110]]

| Attribute | Value |
| --- | --- |
| Cost | $12 |
| Availability | Only appears after a [[Nether Portal]] has been redeemed this run |
| Internal key | `v_balacraft_end_portal` |

## Effect
**Open the gateway and warp to a random End biome now.** Redeeming it switches your current run into the **End** dimension — your next ante rolls a random End biome and the selection pool becomes the End set for the rest of the run. See [[Biomes]].

Redeeming it also adds **+1 to your lifetime End-Portal buy count**, working toward unlocking the [[End Deck]] (10 buys).

## Requirement
This voucher is gated behind the [[Nether Portal]] — it only shows up in the shop once you've redeemed a Nether Portal during the same run.
