BalaCraft adds two voucher pairs:
- **Portal vouchers** ([[Nether Portal]], [[End Portal]]) change your **dimension** mid-run; buying them repeatedly unlocks the dimension decks (see [[New Decks]], [[Biomes]]).
- **Enchanting vouchers** ([[Enchanting Table]], [[Sorcerer's Tome]]) unlock and upgrade the [[Enchanting]] system, and each grants **+1 consumable slot**.

| Voucher | Cost | Effect | Availability |
| --- | --- | --- | --- |
| [[Nether Portal]] | $10 | Warp to a random Nether biome now | Available from the start |
| [[End Portal]] | $12 | Warp to a random End biome now | Only after redeeming a Nether Portal this run |
| [[Enchanting Table]] | $10 | Unlock [[Enchanting Books]] + [[Enchanting Pack]]; +1 consumable slot | Available from the start |
| [[Sorcerer's Tome]] | $12 | Books appear more often + Tier III unlock; +1 consumable slot | Only after an Enchanting Table this run |

> Portal vouchers don't *directly* unlock anything permanent — they warp the current run and tick a lifetime "buys" counter. Reaching **10 buys** of a portal unlocks that dimension's deck.
