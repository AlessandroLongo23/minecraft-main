*Voucher*

![[voucher_nether_portal.png|110]]

| Attribute | Value |
| --- | --- |
| Cost | $10 |
| Availability | In the shop from the start of the run |
| Internal key | `v_balacraft_nether_portal` |

## Effect
**Light the portal and warp to a random Nether biome now.** Redeeming it switches your current run into the **Nether** dimension — your next ante rolls a random Nether biome, and the biome selection pool becomes the Nether set for the rest of the run. See [[Biomes]].

Redeeming it also:
- **Unlocks the [[End Portal]]** voucher for the rest of this run (it won't appear until you've taken a Nether Portal).
- Adds **+1 to your lifetime Nether-Portal buy count**, working toward unlocking the [[Nether Deck]] (10 buys).
