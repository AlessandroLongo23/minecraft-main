| Attribute | Value |
| --- | --- |
| Cost | $10 |
| Availability | In the shop from the start (when enchanting is enabled) |
| Internal key | `v_balacraft_enchanting_table` |

## Effect
Unlocks the **[[Enchanting]]** system:
- **[[Enchanting Books]]** start appearing in the shop, and the **[[Enchanting Pack]]** booster can roll.
- Grants **+1 consumable slot** (room for tools *and* books).

## See also
Upgrade it with the **[[Sorcerer's Tome]]** voucher for more books, Tier III, and another slot.
