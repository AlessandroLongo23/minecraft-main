*Common Joker*

| Attribute | Value |
| --- | --- |
| Rarity | Common |
| Cost | $3 |
| Sell value | $1 |
| Unlock | Available by default |
| Internal key | `j_balacraft_itshome` |

## Effect
**×1.5 Mult** if the played hand contains **2 or fewer cards**.

## Notes
- The check counts the cards actually played (or, if none are played yet, the highlighted cards), so it pairs well with single-card / two-card builds.
- Blueprint / Brainstorm / Eternal / Perishable compatible.
