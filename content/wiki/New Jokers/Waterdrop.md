*Uncommon Joker*

| Attribute | Value |
| --- | --- |
| Rarity | Uncommon |
| Cost | $4 |
| Sell value | $2 |
| Unlock | Available by default |
| Internal key | `j_balacraft_waterdrop` |

## Effect
Permanently gains Mult every time you beat a blind **using only one hand**:
- **×0.10 Mult** for each **Small** or **Big** blind beaten in a single hand.
- **×0.25 Mult** for each **Boss** blind beaten in a single hand.

The accumulated multiplier (tooltip *"Currently ×N Mult"*) is applied whenever the joker scores. It starts at ×1 and only begins multiplying once it has grown past ×1.

## Notes
- The "one hand" check is `hands_played == 1` at end of round, so spending a discard is fine — only **playing** more than one hand forfeits the bonus.
- Blueprint / Brainstorm / Eternal / Perishable compatible.
