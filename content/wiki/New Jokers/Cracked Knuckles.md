*Common Joker*

| Attribute | Value |
| --- | --- |
| Rarity | Common |
| Cost | $3 |
| Sell value | $1 |
| Unlock | Available by default |
| Internal key | `j_balacraft_crackedknuckles` |

## Effect
Permanently gains **+50 Chips and +5 Mult** each time you **beat a Small Blind**. Both bonuses accumulate for the rest of the run (tooltip *"Currently +N Chips and +N Mult"*) and are applied whenever the joker scores.

## Notes
- Only Small Blinds count — Big and Boss blinds do not grow it.
- Blueprint / Brainstorm / Eternal / Perishable compatible.
