*Uncommon Joker*

| Attribute | Value |
| --- | --- |
| Rarity | Uncommon |
| Cost | $3 |
| Sell value | $1 |
| Unlock | Available by default |
| Internal key | `j_balacraft_menace` |

## Effect
Gains **×0.25 Mult** each time a **High Card** poker hand is played. The bonus is permanent and accumulates for the rest of the run (tooltip shows *"Currently ×N Mult"*). The accumulated multiplier is applied whenever the joker scores.

## Notes
- Blueprint / Brainstorm compatible.
- Eternal / Perishable compatible.
- The scaling only triggers on a hand whose poker type is exactly **High Card**.
