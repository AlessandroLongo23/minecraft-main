*Rare Joker*

| Attribute | Value |
| --- | --- |
| Rarity | Rare |
| Cost | $3 |
| Sell value | $1 |
| Unlock | Available by default |
| Internal key | `j_balacraft_elytra` |

## Effect
**Sell this joker to instantly beat the current blind.** Selling Elytra while you are selecting a hand immediately sets your score to the blind's requirement and ends the round as a win — no cards played.

## Notes
- Only works while you are in the hand-selection phase of a round (`SELECTING_HAND`). Selling it in the shop does nothing special.
- **Not** Blueprint / Brainstorm compatible (the effect triggers on *selling itself*, so it can't be copied).
- Eternal / Perishable compatible — though Eternal jokers can't be sold, which would disable the effect.
