*Tag — earned by skipping a blind*

| Attribute | Value |
| --- | --- |
| Reward | ≈ one level of XP |
| Lane | [[Experience]] |
| Internal key | `tag_balacraft_xp` |

## Effect
Earned by skipping a blind. Grants enough **[[Experience|XP]]** for about **one level** at your current
level (it scales with the Minecraft leveling curve, so it's worth more the deeper you are). Useful when
you're saving levels to generate an [[Enchanting Books|Enchanting Book]] at the [[Enchanting Table]].

## Notes
- Only appears when the [[Experience|XP]] system is enabled.
