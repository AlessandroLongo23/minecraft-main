Tags are rewards you earn by **skipping a blind**. Vanilla Balatro has tags that hand you booster
packs, money, edition jokers, and so on. BalaCraft adds six MC-native tags that each feed a different
subsystem — including two that deliver the mod's **new pack types**.

The base game's tags still appear normally; these are **added** alongside them. Each tag only shows up
when its subsystem is enabled, so you never roll a dead tag.

| Tag | Reward |
| --- | --- |
| [[Loot Tag]] | a free [[Booster Packs\|Loot Chest]] pack, opened on the skip |
| [[Food Tag]] | a free [[Booster Packs\|Food Pack]], opened on the skip |
| [[Mining Tag]] | 3 ore right now |
| [[XP Tag]] | about one [[Experience\|level]] of XP |
| [[Blacksmith Tag]] | a free random [[Tools\|Tool]] |
| [[Explorer Tag]] | +1 choice at the next [[Biomes\|biome]] select |
