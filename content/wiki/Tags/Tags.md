Tags are rewards you earn by **skipping a blind**. Vanilla Balatro has tags that hand you booster
packs, money, edition jokers, and so on. BalaCraft adds six MC-native tags that each feed a different
subsystem — including two that deliver the mod's **new pack types**.

The base game's tags still appear normally; these are **added** alongside them.

| Tag | Reward |
| --- | --- |
| [[Loot Tag]] | free [[Booster Packs\|Loot Chest]] next shop |
| [[Food Tag]] | free [[Booster Packs\|Food Pack]] next shop |
| [[Mining Tag]] | a stack of [[Resources\|ores]] right now |
| [[XP Tag]] | about one [[Experience\|level]] of XP |
| [[Blacksmith Tag]] | a free random [[Tools\|Tool]] |
| [[Explorer Tag]] | a free reroll at the next [[Biomes\|biome]] select |
