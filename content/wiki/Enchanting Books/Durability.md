## Effect
Applied to any **[[Tools|tool]]**, Durability **multiplies its max Uses** (rounded up) and grants the extra uses immediately. Base Uses are Wooden 1 / Stone 2 / Iron 3 / Golden 3 / Diamond 4 — so a Diamond tool (4) with Durability III (×2) lasts **8 blinds**.

## Applying
**Dual-target.** Select a **tool** + this book → **Enchant** (costs `book tier + material tier − 1` [[Experience|levels]]; one per tool, higher tier upgrades). Or select a **card in hand** + this book → **Enchant Card** to apply the [[Editions/Unbreaking\|Unbreaking edition]] (can't be debuffed by bosses; Glass won't break — **flat**, any tier, costs 2 levels). See [[Enchanting]].
