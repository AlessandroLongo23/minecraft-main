| Attribute | Value |
| --- | --- |
| Appears from | Ante 2 |
| Score requirement | Standard boss (×2) |
| Resource drop | **2× Coal** (themed) |
| Mob attack | **6 ♥ (3 hearts)** on a failed hand |
| Internal key | `bl_balacraft_creeper` |

## Effect
If you **beat the blind on your last hand** (no hands left), the Creeper "explodes" and **destroys a random joker**. Eternal jokers are safe. If you beat it with hands to spare, nothing is destroyed — so leaving a hand in reserve neutralizes it.
