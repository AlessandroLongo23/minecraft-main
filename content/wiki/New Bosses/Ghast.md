*Nether boss blind*

![[boss_ghast.png|120]]

| Attribute | Value |
| --- | --- |
| Appears from | Ante 2 |
| Score requirement | Standard boss (×2) |
| Resource drop | Tier-roll (2× of a random ore, tier scales with ante) |
| Mob attack | 2 ♥ (1 heart) on a failed hand |
| Internal key | `bl_balacraft_ghast` |

## Effect
**After each hand is scored, every card left in your hand has a 1-in-2 (50%) chance to be destroyed.** *However*, **playing a Straight (or Straight Flush) instantly beats the blind** — reflect the Ghast's fireball back at it.

## Notes
- The instant-win sets the blind requirement to 0 the moment a Straight is played, so the destruction roll never matters if you open with one.
