*Overworld boss blind*

![[boss_slime.png|120]]

| Attribute | Value |
| --- | --- |
| Appears from | Ante 2 |
| Score requirement | Standard boss (×2) |
| Resource drop | Tier-roll (2× of a random ore, tier scales with ante) |
| Mob attack | 2 ♥ (1 heart) on a failed hand |
| Internal key | `bl_balacraft_slime` |

## Effect
The fight itself is normal, but **after you beat it the slime "splits"**: next ante's **Small Blind requirement is ×1.5** and its **Big Blind requirement is ×1.25**. The pain is deferred to the following ante rather than the boss round itself.
