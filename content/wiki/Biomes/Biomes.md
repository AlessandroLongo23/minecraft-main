Implemented: 13 selectable biomes across 3 dimensions (+ the ritual-only [[Stronghold]])

---
Biomes and dimensions reshape each run. A **dimension** (Overworld, Nether, End) is a set of biomes; a **biome** is the theme for a single ante.

## Dimensions
- **Overworld** — where every run starts by default (in [[Plains]]).
- **Nether** — reached mid-run by lighting a **Ruined Portal** blind with [[Flint and Steel]] (+ 1 [[Obsidian]]), or by starting with the [[Nether Deck]].
- **End** — reached mid-run via the **Eye-of-Ender trail** (use an [[Eye of Ender]] across three consecutive antes through the [[Stronghold]]), or by starting with the [[End Deck]].

There are **no portal vouchers** — travel is structure-based. See [[Dimensions]] for the full travel rules. Selection pools are dimension-isolated: once you're in the Nether you pick from Nether biomes, etc.

## How biomes work
- **Picked each ante.** After every Boss cash-out, before the shop opens, you choose **1 of 3 biomes** from your current dimension (your current biome is excluded). Selection only appears if the dimension has ≥ 2 biomes — so once you reach **[[The End]]** (a single biome) you simply stay there.
- **Background tint.** The chosen biome recolors the table for non-boss states.
- **Ore bias.** Each biome weights which [[Resources|ores]] you roll from drops (see each biome's *ore bias*).
- **Arrival bonus.** Some biomes give a one-time $ bonus or penalty the moment you enter.
- **Exclusive bosses.** Three biomes add their own [[New Bosses|boss]] to the pool: [[Forest]] → [[The Overgrowth]], [[Basalt Deltas]] → [[Magma Lord]], [[The End]] → [[Ender Sentinel]].
- **Decks.** Each Overworld biome has an unlockable start-deck (see [[New Decks|Biome Decks]]).
